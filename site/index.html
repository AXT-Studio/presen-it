JSRで入手 READMEを読む

3ステップではじめる

  1. 1追加する

    pnpm add -D jsr:@ayaexptech/presen-it

    Vite+なら vp add jsr:@ayaexptech/presen-it

  2. 2設定する

    // vite.config.ts
import { defineConfig } from "vite";
import presenit from "@ayaexptech/presen-it";

export default defineConfig({
  plugins: [presenit()],
});

  3. 3書いて、開く

    # src/slides/talk/index.md
# はじめに

<!-- presen-it! slide-break -->

## 少しずつ、伝える

    vite を起動して /slides/talk/ を開くだけ。

発表に必要なものは、ひと通り

  • Markdownのまま

    コメント形式のディレクティブだけで改ページ・段組み・段階表示。読み物としても自然です。

  • スライドが主役

    画面いっぱいの投影表示。操作バーは必要なときだけ現れます。

  • 発表者ビュー

    ノート・次の表示・タイマー。別タブの投影画面とページやRevealが同期します。

  • 本番のための機能

    スライド一覧、レーザーポインター、ブラックアウト、プレゼンリモコン対応。

  • コード・数式・図

    Shikiのハイライト、KaTeX、Mermaid、GitHub形式のAlertsに対応。

  • そのまま公開・PDF

    静的ファイルとしてビルドしてデプロイ。ブラウザの印刷からPDFとして保存できます。
